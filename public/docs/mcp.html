nestegg MCP server

Deterministic personal-finance calculators your AI assistant can call — loans, investing, retirement, and exact German payroll math. Free, no account, nothing stored.

What it is

A remote Model Context Protocol server at https://nestegg.money/mcp (Streamable HTTP, no authentication). Every tool is a pure function: your inputs are used to compute a result and then discarded — nothing is written to a database and request bodies are never logged. Read-only by design.

Coverage: loans & mortgages (full amortization with extra payments and rate-fixed periods), time value of money, investing & risk, bonds, options, retirement & FIRE, real estate, business ratios, VAT, and a German set — exact net salary, capital-gains tax, child benefit, Midijob and pension points — built on the official BMF payroll specification and verified against its published test values. The full list with every input and output is in the calculator reference.

Setup

Claude (web/desktop): add it from the Connectors directory, or via Settings → Connectors → Add custom connector with the URL https://nestegg.money/mcp. No login step follows — there are no accounts.

Claude Code:

claude mcp add --transport http nestegg https://nestegg.money/mcp

Any other MCP client: point it at the same URL with the Streamable HTTP transport. The server descriptor is published at /.well-known/mcp.json and in the official MCP registry as io.github.VladimirWrites/nestegg-calculators.

Without MCP: the same calculators are plain JSON endpoints — POST https://nestegg.money/api/calc/<name>, and GET /api/calc lists them.

Example prompts

  • "I have a €475,000 mortgage at 3.75%. If I pay an extra €300/month, how much interest do I save and when am I debt-free?"
  • "What's the net monthly salary for €85,000 in Berlin, tax class 1, TK health insurance?"
  • "I'm 34 with €210,000 invested, saving €2,500/month at 5% real returns — when do I reach €1.5M, and how long does it last at €45,000/year spending?"
  • "I put in €10,000, added €500 monthly for 6 years, now it's €62,000 — what was my annualized return?"

Behaviour & limits

  • Rates, prices, and exchange rates are inputs — the tools never fetch live data. The one exception with built-in data is the German statutory set, which carries the official figures for recent tax years.
  • Results are compact by default: a 30-year amortization returns per-year totals unless monthly detail is requested; long schedules paginate (360 rows per page via offset/nextOffset).
  • Every result carries a calculator version in _meta for reproducibility.
  • Numbers, never advice: outputs depend entirely on the figures and assumptions supplied.

Troubleshooting

  • "Unknown tool" or empty tool list — confirm the URL is exactly https://nestegg.money/mcp (no trailing path) and the transport is Streamable HTTP, not SSE.
  • "Invalid arguments" — the error names the field; every tool's schema is in the reference. Amounts are plain numbers, rates are percents (e.g. 3.75), dates are ISO YYYY-MM-DD.
  • A German tax year is rejected — de-net-salary and its siblings carry data for recent years only; the error lists the supported ones. For older years use de-gross-to-net and supply the figures yourself.
  • Result seems off — check the assumptions field in the result; defaults (like the average health-insurance surcharge) are stated there and can be overridden.
