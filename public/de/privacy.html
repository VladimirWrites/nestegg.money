Datenschutzerklärung

Zuletzt aktualisiert: 28. Juni 2026 · English version

nestegg („die App") ist ein persönlicher Vermögens-Tracker, gebaut, um Ihre Finanzdaten privat zu halten. Diese Erklärung beschreibt genau, was erhoben wird und was nicht. Die Kurzfassung: Wir können Ihre Daten nicht lesen — und wollen es auch nicht.

Kein Konto, keine Identität

Es gibt keine E-Mail, keinen Namen, keine Telefonnummer, kein Passwort. Ihr einziges Zugangsmerkmal ist eine zufällig erzeugte Kontonummer, erstellt in Ihrem Browser. Wir fragen nichts ab und erhalten nichts, was Sie persönlich identifiziert.

Was der Server speichert

  • Einen Konto-Hash (Einwegfunktion) aus Ihrer Kontonummer — nur als Speicheretikett verwendet; er lässt sich nicht in Ihre Nummer zurückrechnen.
  • Einen verschlüsselten Datenblock Ihres Kontobuchs, den der Server nicht entschlüsseln kann.
  • Den Zeitstempel Ihrer letzten Synchronisation.

Wie Ihre Daten verschlüsselt werden

Ihr Kontobuch wird in Ihrem Browser mit AES-256-GCM verschlüsselt. Der Schlüssel wird per PBKDF2 aus Ihrer Kontonummer abgeleitet und verlässt Ihr Gerät nie. Der Server hält ausschließlich Geheimtext und kann Ihre Anlagen, Werte oder Summen nicht sehen.

Was der Server dennoch sieht

Zero-Knowledge gilt für den Inhalt Ihres Kontobuchs, nicht für alle Metadaten. Wie bei jedem Webdienst können der Server (und unser Hoster, Cloudflare) die Größe Ihrer verschlüsselten Daten, den Zeitpunkt der Synchronisation und Ihre IP-Adresse in üblichen Zugriffsprotokollen sehen. Ihre Zahlen lassen sich daraus nicht ablesen.

Beim erstmaligen Anlegen eines Kontos speichern wir kurzzeitig die anlegende IP-Adresse (bis zu 24 Stunden), ausschließlich zur Begrenzung von Registrierungen und zum Schutz vor Missbrauch. Sie wird nicht mit Ihrem Konto oder Ihren Daten verknüpft und nach Ablauf des Zeitfensters automatisch gelöscht.

Eine Anmerkung zum Vertrauen

Da die Verschlüsselung in Code läuft, den Ihr Browser von uns lädt, hängt die Datenschutzgarantie davon ab, dass dieser Code nicht manipuliert ist. Wir liefern die App als statische Dateien aus und halten sie prüfbar. Für maximale Sicherheit können Sie den Quellcode auf GitHub einsehen und mit Export JSON ein unabhängiges Backup führen.

Daten von Dritten

  • Wechselkurse stammen von der Frankfurter-API (Referenzkurse der Europäischen Zentralbank). Es werden keine persönlichen Daten übertragen.
  • Wertpapierkurse werden über einen serverseitigen Proxy bei Yahoo Finance abgefragt. Übertragen wird nur das öffentliche Tickersymbol — nie Ihre Identität, Ihre Bestände oder Ihr Konto.
  • Hosting durch Cloudflare (Workers + D1).

Rechner & MCP-API

nestegg stellt seine Finanzmathematik auch als öffentliche Rechner bereit — JSON-Endpunkte unter /api/calc/* und einen Model-Context-Protocol-Server unter /mcp, den KI-Agenten aufrufen können. Das ist ein zustandsloser, entfernter Dienst: Da die Berechnung auf dem Server läuft, werden die von Ihnen gesendeten Werte (Beträge, Sätze, Daten) über das Netz übertragen. Der Server verwendet sie nur zur Berechnung des Ergebnisses und verwirft sie dann — sie werden in keine Datenbank geschrieben und nicht mit Ihnen verknüpft (es gibt auf diesen Endpunkten kein Konto und keinen Login), und Anfrageinhalte werden nicht protokolliert. Wie bei jeder Webanfrage können übliche Metadaten (IP-Adresse, Zeitstempel) in den Protokollen von Cloudflare erscheinen. Die Rechner schlagen nichts über Sie nach und liefern ausschließlich Zahlen, nie Finanzberatung.

Kein Tracking

Keine Cookies, keine Analyse-Tools, keine Werbung, keine Tracker von Dritten.

Daten auf Ihrem Gerät

Aus Komfortgründen bleiben Ihre Kontonummer und eine entschlüsselte Kopie Ihres Kontobuchs im lokalen Speicher Ihres Browsers, damit Sie angemeldet bleiben. Abmelden oder das Löschen der Browserdaten entfernt sie von diesem Gerät.

Keine Wiederherstellung

Wenn Sie Ihre Kontonummer verlieren, können Ihre synchronisierten Daten von niemandem wiederhergestellt werden — auch nicht von uns. Das ist eine direkte Folge des Verschlüsselungsdesigns. Bewahren Sie Ihre Nummer sicher auf und exportieren Sie Backups.

Löschen Ihrer Daten

Auf Ihrem Gerät löschen Sie alles über „Reset" oder „Log out". Ihr verschlüsselter Datenblock kann auf Anforderung Ihres Clients vom Server entfernt werden.
